## Overview

This repository provides an automated, machine-readable metadata index (`CSV`, `JSONL`, Frictionless `datapackage.json`, `CITATION.cff`, Wikidata QuickStatements, and per-jurisdiction Markdown dossier catalogs in `catalogs/`) of official government regulations, statutory instruments, legislation, central bank circulars, supreme audit reports, and multilateral resolutions indexed by **[Index Data](https://www.indexdata.org)**.

Full analytical briefings, structured HTML compliance matrices, semantic definition lists, two-stage Tables of Contents, authority RSS syndication feeds, Page 1 visual previews, and unabridged source PDF dossiers are available directly via each record's `canonical_url` on [indexdata.org](https://www.indexdata.org).
